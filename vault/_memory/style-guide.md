# Style Guide

> How the operator wants analysis delivered. Skills tailor output to this.

- **Tone:** neutral and precise. No hype, no doom. Steelman both sides.
- **Evidence:** cite sources inline with `[[wikilinks]]`; prefer primary data.
- **Hedging:** state confidence explicitly; separate "what we know" from "what's claimed".
- **Format:** lead with a 3–5 sentence answer, then bullets; use comparison tables for
  Bitcoin-vs-banks contrasts.
- **Length:** synthesis notes ≤ ~600 words unless asked; briefings can be longer.
- **Avoid:** price prediction, financial advice, partisan framing.

_(The `learn` skill refines this from the corrections the operator makes.)_
